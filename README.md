## 🧠 Conhecimentos em IA Generativa

| Conceito | O que significa na prática |
|---|---|
| 🎯 **Prompt Engineering** | Criar instruções claras para obter respostas precisas dos modelos |
| 📚 **RAG** (Geração Aumentada de Recuperação) | Conectar LLMs a bases de conhecimento para respostas fundamentadas |
| 🧷 **Grounding** | Ancorar as respostas da IA em fontes confiáveis e verificáveis |
| 🔁 **Agentic Reasoning Loop** | Agentes que planejam, agem e se corrigem em ciclos |
| 🤝 **Model-based Agent AI** | Agentes que mantêm um modelo do ambiente para decidir melhor |
| ⚙️ **Automatic Workflows** | Automação de processos ponta a ponta com IA |
